# Dev-сертификаты

## Что есть
- `certs/dev-ca.crt` / `certs/dev-ca.key` — dev CA (ECDSA P-256).
- `certs/dev-server.crt` / `certs/dev-server.key` — leaf для localhost
  и 127.0.0.1.

## Правила
- Коммитятся **только** dev-сертификаты. Прод-ключи в VCS не попадают.
- При публикации репозитория — проверить, что dev-ключи явно помечены
  как test-only в README и не используются в prod-конфигурациях.
- Перевыпуск: см. скрипт/инструкцию в `certs/README.md` (добавить
  при следующем спринте, если перевыпуск понадобится).
- `dev-ca.key` после компрометации (например, случайной публикации
  репозитория) считается скомпрометированным; перевыпуск цепочки
  обязателен.
