# Опциональные профили и направления исследований

## Режимы клиента

| Ось | Значение | Статус |
|---|---|---|
| `mode` | `socks5` | MVP, обязательный |
| `mode` | `tun` | Phase 2 (после SOCKS5) |
| `entry` | `none` | MVP |
| `entry` | `wireguard` (AmneziaWG) | MVP, опционально |
| `profile` | `direct` | MVP, обязательный |
| `profile` | `camouflaged` | MVP, опциональный |

## Профили развёртывания

| Профиль | Статус | Зависимости | Когда использовать |
|---|---|---|---|
| A — Direct | Обязательный, MVP | TLS-сертификат | Сети без активного DPI; fallback |
| B — Camouflaged entry | Опциональный, MVP | Домен, nginx, фейковый сайт, Reality, DNS-01 | Сети с активным ТСПУ |
| C — CDN-fronted | Экспериментальный | Российский CDN/облако с «белыми» IP | Только после ADR |
| D — Serverless-мосты | Исследовательский | Serverless-функции | Не в MVP |

## Опциональные транспорты и механизмы

| Механизм | Тип | Статус | ADR |
|---|---|---|---|
| AmneziaWG (wireguard-entry) | entry-режим | В MVP (опционально) | ADR-016 |
| AmneziaWG как UDP-транспорт к серверу | Транспорт | Опциональный адаптер | ADR-015 |
| MASQUE / TrustTunnel | QUIC-транспорт | Направление развития | ADR-015 |
| Фрагментация TLS ClientHello | Клиентская настройка | Опционально | ADR-015 |
| Reality + mux | Механизм маскировки | В MVP (Profile B) | ADR-014 |

## Правило
Ни один опциональный профиль или транспорт не является обязательной
зависимостью базовой сборки. Каждый требует отдельного ADR.
