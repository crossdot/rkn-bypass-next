# Threat Model — РФ-специфичные угрозы

| Угроза | Актив | Меры | Остаточный риск |
|---|---|---|---|
| Блокировка по сигнатуре протокола | Возможность подключения | Reality, mux, нестандартные порты; быстрая смена конфигурации | Средний |
| Блокировка по IP-подсети хостинга | Доступность сервера | Диверсификация хостингов, быстрая замена IP | Высокий |
| Блокировка по SNI/домену | Точка входа | Пул доменов, быстрая замена, непопулярный SNI | Средний |
| Фильтрация облачной инфраструктуры | Доступность сервера | Не размещать точку входа на российских облачных площадках | Высокий |
| Активное зондирование (probing) | Скрытность сервера | Fallbacks отдают валидный TLS фейкового сайта | Низкий при корректной настройке |
| DDoS / фишинг против инфраструктуры | Сервер, команда | OPSEC, изоляция админ-доступа, rate limiting | Средний |
| Обнаружение через российские приложения | Приватность пользователя | Документально предупредить; не полагаться на РФ-приложения | Высокий |
| Компрометация домена или сертификата | Точка входа | Процедура быстрой замены домена и перевыпуска конфигураций | Средний |
| Блокировка голого WireGuard по handshake | wireguard-entry | Использовать только AmneziaWG; TCP/443 на мобильных | Низкий при AmneziaWG |
| Блокировка UDP на мобильных операторах | wireguard-entry | TCP/443-режим AmneziaWG | Средний |
| Компрометация клиента-точки-входа | Доступ конечных пользователей | Изоляция доступа, лимиты, отзыв на точке входа | Средний |
