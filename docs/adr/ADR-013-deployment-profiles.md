# ADR-013: Профили развёртывания и опциональность camouflaged entry

## Статус: Принято

## Решение
1. Вводятся профили: A (Direct), B (Camouflaged entry), C (CDN-fronted,
   экспериментальный), D (Serverless, исследовательский).
2. Camouflaged entry — опциональный профиль, не обязательное требование.
3. Profile A полностью функционален без домена и фейкового сайта.
4. Profile B не вводит обязательных зависимостей в `transport-api`,
   `protocol` или `crypto`.
5. Транспорт и протокол не знают о профиле.
6. Политика выбора транспорта не выбирает профиль автоматически.
7. Критерии выбора Profile B: активный ТСПУ, доступность домена и хостинга
   вне российских облачных площадок, готовность оператора поддерживать
   фейковый сайт и ротацию сертификата.

## Последствия
- Появляется `deploy/profiles/` с отдельными наборами артефактов.
- Тесты и нагрузка идут раздельно по профилям.
- `cargo build` и базовый Docker-образ сервера не требуют nginx.
