# ADR-014: Camouflaged entry (Profile B) — self-steal архитектура

## Статус: Принято как опциональный профиль (MVP)

## Решение
1. 443/tcp слушает Xray (VLESS+Reality).
2. Неаутентифицированные TLS-соединения через Fallbacks идут на локальный
   nginx с фейковым сайтом.
3. Соединения с правильным ключом Reality обрабатываются как туннель.
4. Сертификат — реальный (Let's Encrypt через DNS-01, acme.sh + Cloudflare API),
   с автоматической ротацией.
5. Фейковый сайт — настоящее веб-приложение: реальные тексты, `/privacy`,
   `/terms`, `robots.txt`, нейтральная тематика.
6. Контактный email не совпадает с названием VPN-проекта.
7. SNI — непопулярный, не `google.com` и не `apple.com`.
8. Домен и IP — вне российских облачных площадок, упоминаемых в связи
   с фильтрацией ТСПУ.
9. Компрометация домена или сертификата = компрометация точки входа.
   Процедура реагирования включает замену домена и перевыпуск конфигураций.

## Обязательные тесты
- Активный пробинг 443 без ключа Reality возвращает валидный TLS-хендшейк
  фейкового сайта, а не ошибку.
- Тест повторяется после каждого обновления Fallbacks.
- Переключение между Profile A и Profile B по явной команде работает
  без изменения прикладного кода.
- Сервер стартует в Profile A без домена, сертификата и nginx.
