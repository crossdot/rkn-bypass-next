# ADR-018: MSRV = 1.85 (edition2024 в транзитивных зависимостях)

## Статус: Принято

## Контекст
`rustls` 0.23 неопционально зависит от `zeroize`. Версии `zeroize` 1.9.x
перешли на edition2024, что требует Cargo ≥ 1.85. Пиннинг каждого
транзитивного пакета к старым версиям хрупок и создаёт долг сопровождения.

## Решение
1. MSRV проекта — 1.85. Зафиксирован в `rust-toolchain.toml`
   (`channel = "1.85.0"`), `rust-version = "1.85"` в workspace
   и в CI.
2. `edition` кода остаётся 2021. Переход на edition2024 — отдельное
   решение, не связанное с MSRV.
3. Понижение MSRV обратно не выполняется без нового ADR с обоснованием.
4. При обновлении зависимостей MSRV не поднимается автоматически;
   повышение — отдельный PR с указанием причины.

## Последствия
- CI и локальные окружения требуют Rust ≥ 1.85.
- MSRV остаётся управляемым: повышение — осознанное решение,
  а не побочный эффект `cargo update`.
- Edition2024 в собственном коде не используется; миграция — отдельно.
