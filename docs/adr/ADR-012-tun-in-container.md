# ADR-012: TUN внутри контейнера — не в MVP

## Статус: Принято (отложено до Phase 2)

## Решение
1. В MVP TUN-режим клиента не реализуется (ни нативно, ни в контейнере).
2. Основной контейнерный сценарий клиента в MVP — SOCKS5.
3. TUN в контейнере — Phase 2, только как sidecar с `NET_ADMIN`
   и host networking, после стабилизации нативного TUN.
4. `--privileged` не допускается.
5. Все ограничения документируются в `docs/operations/` перед Phase 2.

## Последствия
- Пользователь, которому нужен TUN, получит его в Phase 2.
- Тесты TUN-в-контейнере не входят в MVP.
